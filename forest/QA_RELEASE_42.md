# «Князь и Кудрявый» · Зачарованный лес v42 — герой гуляет по миру

Дата: 1 ноября 2026. База: v41. Ветка разработки: `feature/forest-explorer-v42`.

## Реализовано

- На свободный участок лесной сцены можно нажать пальцем или мышью. Костик/Кирилл плавно перемещается к этой точке по переднему плану. На телефонах целевая позиция ограничена безопасной областью кадра, чтобы персонаж не исчезал за краем.
- При нажатии на один из восьми интерактивных объектов v41 герой сначала подходит к нему, а после прибытия происходит реакция мира с существующими анимациями и звуками.
- При нажатии на любой из восьми секретов v40 герой также подходит к секрету перед его открытием. Счётчик, медали и сохранения секретов оставлены прежними.
- Подход к сове Луне, садовому ростку, поющим камням и драконьему гнезду, а также к трём сюжетным светлячкам.
- Быстрое повторное нажатие меняет цель без выполнения старого отложенного действия; смена героя, этапа или сцены отменяет незавершённое действие.
- Анимация шагов, светящаяся отметка цели, строка состояния с `aria-live` для простых подсказок.
- Системное и внутриигровое отключение анимаций делает переход мгновенным, не блокируя действия.
- Оригинальные CSS и JavaScript без библиотек, сетевых вызовов и новых постоянных данных. Существующие сохранения достижений остались совместимы.
- Бамп кэша игры: `forest3.html?v=16`, `forest3.js?v=19`, `forest3-art.js?v=3`, `forest3-world.js?v=2`, `forest3-explore.js?v=1`; возврат в Академию `?v=42`.

## Выполненные проверки

1. Разбор всех изменённых JS через компилятор JavaScript (`new Function`) без синтаксических ошибок.
2. Проверка подключения файлов в HTML, порядка загрузки, ссылок между Академией и лесом.
3. Проверка подключения всех 8 предметов, 8 секретов, 4 сюжетных горячих точек и 3 светлячков.
4. Условные DOM-тесты нового контроллера движения: точка подхода, выполнение при прибытии, отмена действия при новом нажатии, отмена при смене сцены, мгновенное действие в режиме reduced-motion, свободное касание земли и игнорирование кликов по кнопкам.
5. Проверка, что история открытий и сюжетные сохранения не менялись.
