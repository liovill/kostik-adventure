# Князь и Кудрявый: звуковая режиссура и актёрские реплики

## Реализовано в игре

- Единая студия голосов (Звездочёт, сова Луна, Искрик).
- Встроенные оригинальные звуковые сигналы событий и спокойные синтезируемые атмосферы для 5 локаций.
- Звуковая среда включается только после явного действия ребёнка/родителя, по умолчанию фоновая атмосфера выключена.
- Уменьшение громкости фона во время речи, управление громкостью и отключение эффектов.
- 36 литературно подготовленных реплик для будущей профессиональной записи.
- Для воспроизведения реплик без записанного файла используется русский голос устройства (speechSynthesis).

**Важно:** в репозитории нет профессионально записанных MP3. Смена pitch/rate браузерной речи и генерация игровых звуков не заменяют запись актёров.

## Роли персонажей

1. **Звездочёт:** взрослый спокойный голос, немного глубже, без чрезмерно замедленного произношения.
2. **Сова Луна:** тёплый голос рассказчицы, ясный и доброжелательный, короткие фразы.
3. **Искрик:** светлый и радостный голос маленького фантастического дракончика, без визгливого тембра.

Звуки должны быть комфортны для ребёнка, без резких громких переходов. Не использовать имитацию голоса реального человека без согласия.

## Как загрузить настоящие записи

1. Сгенерируйте или запишите реплику из файла `voice-lines.js` выбранным голосом персонажа, используя коммерчески лицензированную озвучку.
2. Экспортируйте **MP3**, русский язык, 44.1/48 кГц, без фоновой музыки. Практический ориентир по громкости речи: -18 LUFS и пик не выше -1 dBTP.
3. Разместите файл в GitHub по пути `forest/audio/<имя>.mp3`.
4. В `voice-lines.js` у соответствующего ID замените `"file": null` на `"file": "./audio/<имя>.mp3"`.
5. Обновите версию подключения `voice-lines.js?v=N` в `index.html` и `forest3.html`.
6. Проверьте голос и его резервное воспроизведение на iPhone Safari, Android Chrome, настольном браузере.

Если запись отсутствует или воспроизведение недоступно, игровой движок попытается использовать системный русский голос.

Не храните ключи генераторов речи в браузерном JavaScript или публичном GitHub. Генерируйте аудио на защищённом сервисе/в приложении, затем публикуйте готовые файлы.

## Тестовый маршрут

Открыть Академию → 🎙️ Студия голосов → выбрать темп → включить «Атмосфера волшебного мира» → прослушать сову Луну → открыть Зачарованный лес 3.0 → поговорить с совой → собрать огоньки → вырастить цветы → собрать мост → дойти до Искрика. Проверять на обоих героях и возвращение к старым сохранениям.
