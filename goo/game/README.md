# Костик и Глазастик

Браузерное приключение для Костика: глазастый лизун, прыжки, секреты, головоломки и мультяшные монстры. Игра рассчитана на телефон, поддерживает клавиатуру.

[Играть в опубликованную версию](https://kostik-goo-adventure.rafalovichhhh.chatgpt.site/)

## Запуск

Нужен Node.js 18 или новее. Дополнительных зависимостей и сборки нет.

```sh
npm start
```

Откройте http://127.0.0.1:8080. Для статического хостинга используется содержимое папки `dist/`.

```sh
npm test
```

Команда запускает 14 проверок геометрии, головоломок, боёв, условий победы, экономики и интерфейса.

## Что есть в игре

- 100 уровней в 10 мирах, босс на каждом пятом уровне.
- Первые 10 уровней получили отдельные схемы: верхние и нижние ветки, переменное размещение секретов, возвращение за источником энергии, перенос батареи и подключение ниши в другой комнате.
- Боссы переходят во вторую фазу после потери половины здоровья и сочетают две атаки. Перед каждой атакой есть предупреждение.
- Портал открывается после трёх больших кристаллов, спасения всех малышей, решения обязательных загадок и победы над боссом.
- Три сердца и лечение на уровнях. Попадание сбрасывает текущую комнату; потеря всех сердец начинает весь уровень заново.
- Лазеры, зеркала, ящики и плиты, ключи и замки, последовательности символов.
- Плоская форма для узких проходов с уровня 6, пузырь для воздушных потоков и плавного падения с уровня 7.
- 60 предметов внешности в пяти независимых слотах.
- Русские обращения к Костику, подсказки и озвучка при наличии русского голоса в браузере.
- Три ступени подсказки: обратить внимание, объяснить связь, назвать нужное действие. Автоматические таблички сообщают цель.

## Управление

На телефоне: стрелки, прыжок, кнопка действия ✋, формы ▰ и ○. Кнопка ? даёт подсказку. Повторное нажатие формы возвращает обычного лизуна.

На клавиатуре: стрелки или A/D — движение, пробел — прыжок, 1/S — плоская форма, 2/F — пузырь, E/Enter — действие, H — подсказка, Escape — пауза.

## Структура

| Файл | Назначение |
| --- | --- |
| `dist/core.js` | Создание карт, физика, условия победы |
| `dist/puzzles.js` | Механизмы и головоломки |
| `dist/combat.js` | Поведение боссов |
| `dist/chapters.js` | Авторские схемы первых десяти уровней и связи между комнатами |
| `dist/app.js` | Интерфейс, сохранения, отрисовка |
| `dist/atmosphere.js` | Декорации миров |
| `dist/assets/` | Фоновая графика |
| `docs/graphics.md` | Художественное направление и запрос генерации фона |
| `docs/game-audit.md` | Наблюдения и план дальнейших улучшений |

Прогресс хранится в localStorage текущего браузера. При смене адреса сайта сохранение автоматически не переносится. Фоновое изображение создано генератором изображений; персонажи и игровые объекты рисуются Canvas.

## Границы проверки

Целевое первое прохождение — 5–10 минут на уровень, фактическое время с ребёнком ещё не измерено. Все 100 карт проверены автоматическими сценариями по отдельным механикам. Полное ручное прохождение всей кампании и замер FPS на настоящем телефоне не проводились. Проверки интерфейса используют имитацию Canvas и не заменяют проверку на устройстве.

Новые ветки и ниши проверяются движениями и действиями через игровую физику с отключёнными врагами для изоляции геометрии. Боссы 5 и 10 пройдены отдельным детерминированным контроллером с настоящими атаками, без изменения здоровья. Это не измерение времени или сложности для ребёнка.

Это перенос текущей версии игры. Служебная конфигурация её исходного хостинга и локальные сохранения в репозиторий не входят.
